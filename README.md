# 🌤️ Wearever

Wearever é um app Android que busca o clima atual e redireciona o usuário para a cidade mais próxima que tenha o clima desejado — usando a localização do dispositivo.

## Funcionalidades

- Detecção automática da localização do usuário
- Redirecionamento para a cidade mais próxima com o clima buscado
- Interface simples e intuitiva

## Requisitos

- Android 7.1.1 (API 25) ou superior
- Permissão de localização

##Tecnologias

- Java
- Android SDK 36
- ConstraintLayout
- Material Design

## Como rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Sunref/wearever.git
   ```
2. Abra no Android Studio
3. Sincronize o Gradle
4. Rode em um dispositivo ou emulador com Android 7.1.1+
